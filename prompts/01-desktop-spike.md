执行阶段 1：Windows 桌面宿主与自由缩放的可行性原型。先阅读项目约束和进度；本轮只实现系统窗口风险验证，不做完整业务。

委派 Desktop agent 编写最小可运行 Electron 窗口与 DesktopHostAdapter；QA agent 独立设计并执行可执行的桌面测试。公共脚手架和依赖由你统一修改。可让 UI agent 只读给出布局建议，不与窗口代码重叠。

必须验证：桌面露出时可见，Win+D 后仍可见，普通窗口可覆盖，不主动抢焦点；窗口可连续缩放、拖动，交互区域不被拖动区域吞掉。持久化位置和尺寸，并检查 DPI 和显示器变化。

不要把 alwaysOnTop=false、skipTaskbar=true 当成桌面实现。使用原生桥接或 Shell 相关方案时验证当前系统，记录真实依赖、窗口样式、DPI 与恢复策略；不能把 Shell 内部窗口结构描述为稳定公共 API。不得注入 Explorer 或要求程序以管理员权限常驻。

优先验证不透明可缩放窗口；透明/磨砂另作增强，不要假定 transparent 与 resizable 能稳定组合。真实桌面模式与普通开发降级模式必须有明确可见的区别。
