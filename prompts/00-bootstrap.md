【产品约束】
1. 个人自用，视觉参考 macOS Sonoma Widget。支持中文/英文界面与混合输入，浅色/深色/跟随系统，窗口连续调整大小并保存位置。默认尺寸 480×420 DIP，参考最小 320×240 DIP；不是只允许预设尺寸。
2. Widget 属于桌面：桌面露出时可见，普通应用覆盖时不置顶，Win+D 后仍可见；无普通任务栏/Alt+Tab 条目，不启动抢焦点。只有明确唤起快捷捕获时才聚焦输入。普通非置顶窗口不能冒充桌面宿主。
3. 主界面展示当前待办、今日安排、最近笔记入口。用户只需自然看到事项，不做晨间打卡、阅读确认、强制回顾或操作限时。
4. 支持一天及跨天安排。任务计划日与截止日分开；未完成事项继续可见但不自动改期；未来安排可按日期浏览。日程有开始/结束和跨午夜重叠查询；过去日程不自动标记为已参加。
5. 完成默认长期保留历史，可重新打开；删除先进入可恢复回收站，永久删除需明确确认。删除传播到应用生成的历史日志，恢复可以重建；外部导出/独立备份的副本不承诺同步删除。
6. 快捷捕获默认是笔记，可显式切换任务/日程。Markdown 源码编辑+预览。Enter 换行，Ctrl+Enter 保存成功后收起，Esc 保留草稿；失焦不丢内容。中文输入法候选确认不能误提交。草稿自动保存，写入失败保留内容，防止重复提交。
7. 笔记里的 Markdown 清单只是文档内容，不自动变成独立待办。第一版不做自然语言时间解析或复杂块编辑器。
8. Daily Log 自动汇总当天完成、截至日界线仍待办、当日计划、笔记。当天更新，历史保留当时状态；周二完成不改写周一未完成事实。支持关机跨日后的补生成，幂等，自动区与手写补充区独立，支持 Markdown 导出。
9. UTC 时间、date-only 计划日期、应用时区和历史归属日期必须区分。用可注入 Clock 测跨天，不改用户系统时间，不要求等待到第二天。
10. SQLite 本地持久化，生产/开发/测试数据隔离；不接入云、账号、AI、提醒、重复日程或外部日历。不打包 Apple 品牌素材或字体。真实透明效果可降级，桌面语义和自由缩放不能悄悄删掉。

【技术方向】
Electron + React + TypeScript + electron-vite + SQLite，npm 单仓库；react-markdown/remark-gfm 做预览，electron-builder 打包。先验证兼容的稳定版本并锁定，不照搬过时版本号。SQLite 驱动优先评估 better-sqlite3，但必须在实际 Electron 运行时验证。

主进程负责窗口、数据和受限 IPC；preload 提供类型明确的 API；renderer 不直接访问数据库、文件系统或任意 shell。保持 contextIsolation、sandbox 和关闭 nodeIntegration。Markdown 不执行原始 HTML，不默认加载远程图片。
