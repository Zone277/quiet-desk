# QuietDesk 产品约束与原型规格

本文是可直接实现的工程规格。QuietDesk 只是工程代号，不代表名称已做发布或商标核查。此提示词包不包含已实现的应用代码或已执行的测试结果。

## 目标与平台
个人自用的 Windows 桌面小组件：macOS Sonoma Widget 审美，结合便利贴、待办和按日期查看的日程。主要场景是自然看到当前未完成事项，以及工作中迅速捕获想法。没有晨间确认、打卡、阅读确认按钮或操作时间限制。

优先在用户实际 Windows 环境运行；无其他信息时将 Windows 11 x64 作为首个开发验证目标，并记录实际版本。不能将此默认值解释为用户已经确认系统版本，也不宣称支持未经测试的其他系统。

## 范围与默认技术路线
Electron + React + TypeScript + electron-vite + SQLite，npm 单仓库。Markdown 源码编辑与预览采用 react-markdown / remark-gfm；测试使用 Vitest / 组件测试及适用时的 Playwright Electron 自动化；Windows 打包使用 electron-builder。具体相互兼容的稳定版本由阶段 0/1 调查和实际构建决定，写入锁文件。SQLite 驱动优先评估 better-sqlite3，但必须先验证所选 Electron 版本的原生模块加载和打包；改变候选方案要给出实测原因。

不默认引入 ORM、后端服务器、云服务、账号、AI、自然语言时间解析、自动提醒、重复日程、远程日历同步、附件管理、复杂标签项目体系或块编辑器。开发服务器只能用于开发，打包应用离线运行，不依赖 localhost 常驻服务。

## 桌面语义：硬需求
Widget 在桌面露出区域可见，普通应用窗口覆盖该区域时不浮在其上方。按 Win+D 显示桌面后仍能看到 Widget。Widget 不成为普通任务栏/Alt+Tab 条目，不在启动、日界线变化或数据刷新时抢焦点。只有显式点击或快捷捕获可以触发对应交互。

普通非置顶窗口不是桌面宿主的替代品。若窗口挂接依赖 Shell 内部结构，必须注明非稳定公共契约、验证的 Windows 构建号及失效恢复路径。不注入 Explorer、不替换 Shell，不要求应用日常以管理员身份常驻。

用 DesktopHostAdapter 隔离系统实现，报告当前运行模式。开发降级窗口可以帮助继续做业务，但必须明确显示为开发降级，不能据此宣称桌面功能完成。

## 窗口、主题与视觉
Widget 支持连续拖拽缩放，预设尺寸不是唯一可选尺寸。初始设计尺寸：最小 320×240 DIP、默认 480×420 DIP、参考大尺寸 720×720 DIP；如原生约束需要调整，应给出验证依据而非悄悄移除自由缩放。持久化尺寸和位置；显示器移除或 DPI 变化后回到可见区域。

主题为浅色 / 深色 / 跟随系统；中英文 UI，可读写中英文混排、中文标点与 emoji。界面默认根据系统语言选择中文或英文，未知语言回退英文；内容不自动翻译。

视觉为大圆角、柔和背景、克制阴影、一个强调色、清晰字号与留白。使用本地系统字体，如 Segoe UI 和合适的中文回退。正文可读性优先于真实透明、磨砂和动画。透明能力必须实测；允许使用不透明的精致卡片材料作为第一版视觉降级，但不能放弃桌面行为和自由缩放。

最小尺寸也保留当前事项、今日安排和捕获入口的可发现性，减少条目或显示“还有 N 项”，不按宽度直接丢弃功能。支持键盘焦点、可访问标签和减少动画偏好。日期和关键安排不得只能通过颜色表达。

## 三类界面
1. Widget：当前待办、今日安排、最近笔记简要入口、折叠的今日已完成；不把整套管理 UI 塞入卡片。
2. Quick Capture：用户主动唤起的独立输入窗口，默认创建笔记，可显式切换待办或日程。
3. Library：按日期浏览历史与 Daily Log、编辑 Markdown、查看未来安排、回收站和轻量设置。第一版日期选择器 + 日列表即可，不做完整周时间网格。

## 任务
任务、日程、笔记可以共享 ID/时间元信息，但必须有不同类型的业务约束，不能仅用一个 datetime + completed 表示全部对象。

任务至少具有标题、Markdown 说明、可选计划日期、可选截止日期、完成时间、创建/更新时间、删除标记。计划日期与截止日期分开。无截止日的旧任务不自动标为逾期。

当前待办默认查询“未删除、未完成，且未指定计划日或计划日不晚于当前应用日期”的任务；未来计划任务在后续安排中查看。昨天未完成的任务继续可见，不自动修改其原计划日期或截止日期。

完成后退出当前待办，默认长期保留历史，可重新打开。完成/重新打开/改期等操作记录应支持历史还原。删除先进入回收站，可恢复；永久删除需用户明确确认，不自动清空回收站。

## 日程与跨天
支持按日期查看当天和未来的日程，并支持开始、结束时间及跨午夜/多天安排。时间段采用半开区间，结束必须晚于开始。对某天的重叠判断以该日时区边界为准，不简单使用“开始日期等于今天”。支持全天日程时，明确使用日期范围与不包含结束日，不用假造 UTC 午夜代替日期。

过去的日程仍只是“计划”，不能自动写成用户已经参加。第一版不做重复日程、提醒和外部日历同步。

## 捕获与 Markdown
默认热键为 Ctrl+Shift+Space，可配置；注册失败须提示并保留可用入口，不使用 Ctrl+Space，不强占冲突快捷键。

默认创建 Markdown 笔记，不将自然语言、日期文字或 Markdown 清单自动转换成独立待办。任务需要显式创建，笔记里的 `- [ ]` 是文档内容，不是自动同步到任务数据库的项目。

Enter 换行；Ctrl+Enter 正式保存；Esc 收起并保留草稿。失焦不擅自提交或丢弃。中文输入法组合输入和候选词确认期间不触发提交。用实际中文输入法验证，而不是只模拟按键。

草稿去抖自动持久化，并显示未保存/保存中/已保存/失败状态。保存承诺以持久化成功为准：明确区分尚未落盘输入与已保存草稿，不声称异常断电绝无数据损失。Ctrl+Enter 等待事务成功后才清空草稿和收起窗口；失败保留内容并可重试。防止重复提交和乱序自动保存覆盖较新内容。

Markdown 第一版支持标题、列表、引用、代码块、链接，以及 GFM 表格/删除线/清单。源码编辑 + 预览，不做富文本协同。Widget 只显示摘要，不内嵌完整长表格或代码块。原始 HTML 默认禁用；外链验证；远程图片默认不加载；未支持附件要清楚提示。

## Daily Log
自动结构化汇总，不接入 AI，不推测行为。内容包括：当天完成、截至日界线仍待办、当天安排（明确是计划）、当天记录的笔记，以及独立的手写补充区。

当天日志随已保存数据更新，跨日、启动、唤醒或浏览历史时可补齐。无活动的空白日期可以按需计算，但不必批量创建空日志。重复生成同一天结果幂等，不能生成多个相同日志或重复完成事件。

历史内容依据当时数据状态：周一未完成、周二完成，则周一“截至当天结束仍待办”保持原意，周二记录完成。今天改标题或重新打开，不能无意重写过去的状态。以轻量操作历史/版本快照支持此行为，不引入复杂全量事件溯源平台。

已落盘的用户操作与必要快照尽量在同一事务提交。对同一时间戳的事件提供稳定排序。草稿的逐字输入不进入工作日志。当天完成后再重新打开，日志可以展示完成和重新打开事件，或明确呈现最终状态，但不得将其算作当前已完成；在 CONTRACTS 中固定一种可验证规则。

应用初始时区来自系统并持久化；UTC 时间、date-only 字段、事件归属日期和时区不可混淆。现有历史不因系统时区变化而被自动归入另一日。测试注入 Clock，不修改真实系统时间。

自动汇总区与手写补充区分别存储，重新生成不能覆盖手写文字。生成项保留实体关联以支持删除传播，不只保存无法追溯的 Markdown 大字符串。可导出为 UTF-8 Markdown。

## 删除传播与备份边界
回收站项目在普通列表、搜索/历史列表、自动生成的 Daily Log 和新导出中隐藏，恢复后按原历史可重建。永久删除时逻辑清理应用管理的该实体正文、操作快照和派生缓存；不要声称进行了取证级物理擦除。

用户独立手写的日志文字不因包含相同词语被擅自删除。已经导出的文件及外部/手动备份属于独立副本，界面和 README 应说明不受后续删除自动控制。原型不实现后台自动备份系统；可以提供使用 SQLite 安全快照能力的手动备份，不在数据库打开时草率复制数据库文件。

## 持久化与安全
SQLite 是真实存储，不使用 localStorage 或 demo 内存仓库假装持久化。数据层在主进程侧统一管理；renderer 通过受限 preload/IPC。完成、恢复、重排、草稿正式提交等改变须保证事务边界，并触发其他打开窗口刷新。

SQL 参数化，IPC 做运行时输入校验并限制调用来源；不向 renderer 暴露任意文件读取/写入、原始 SQL 或 shell 命令。使用 contextIsolation、sandbox、关闭 nodeIntegration 和合理 CSP。正式数据位于 Electron userData 的应用专属目录，开发/测试/演示使用不同目录且从启动之初分离。

演示数据只有显式 demo/test 模式才创建，正常用户首次启动不能插入样例。升级迁移不得自动删库重建；记录 schema 版本。诊断日志不输出笔记正文，调试接口不得进入发布构建。

## 验收层次
产品核心完成必须同时覆盖数据/业务、Electron 运行、Windows 桌面行为。浏览器截图不是桌面宿主证据。能构建不等于能运行；开发版能运行不等于打包版本能运行。

权限不足或没有 Windows GUI 时可以交付可运行的开发预览，但必须列出未验证项，不能把“桌面驻留”标为完成。不能为追求虚假的轻量指标省略真实测量；发布构建应记录各 Electron 进程合计内存、闲置 CPU 和启动表现，并注明环境。
