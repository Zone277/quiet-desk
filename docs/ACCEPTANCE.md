# 验收矩阵（规格，不是测试结果）

初始所有项目为 NOT_RUN。实现后为每项补充：自动/人工检查方式、命令或操作步骤、实际平台、结果与证据路径。未执行不可写 PASS。安全与数据丢失缺陷属于阻塞项；桌面宿主缺口阻塞“桌面小组件已完成”的声明，但不阻塞明确标注的业务开发预览。

| ID | 验收情境 | 必须满足的结果 |
| --- | --- | --- |
| A01 | 在实际 Windows 上启动，按 Win+D，打开普通应用覆盖 Widget | 显示桌面时 Widget 可见，普通窗口覆盖时不置顶；记录系统版本与实际模式 |
| A02 | 查看任务栏/Alt+Tab，启动应用，午夜或数据更新 | Widget 无普通任务条目且不自行抢焦点；独立编辑窗口行为单独定义 |
| A03 | 从 480×420 拖到 437×386、320×240 等非预设尺寸并重启 | 连续缩放有效，交互不被拖拽区域吞掉，尺寸位置恢复，全部模块可发现 |
| A04 | 100%/150%/200% DPI、切换显示器、移除原显示器 | 实测配置无严重布局或命中偏移，窗口返回可见工作区；未具备配置则标未测 |
| A05 | 授权测试环境中 Explorer 重启、睡眠/唤醒 | 桌面宿主恢复或清楚显示失败与重试入口，不静默变成悬浮窗；实现不注入 Explorer，也不要求管理员权限常驻 |
| A06 | 中文/英文 UI，浅色/深色/跟随系统，长中英混排文本 | 设置生效并持久化；未知系统语言回退英文；文字可读；无硬编码残余或严重截断；键盘焦点、可访问标签与减少动画偏好有效 |
| A07 | 创建昨天计划的任务但不完成，切换测试时钟到今天 | 仍在当前待办；原计划和截止日不自动变化；未来任务仍只在未来安排 |
| A08 | 完成任务，重启，再重新打开 | 当前列表与历史一致；完成历史保留；重新打开回到符合日期的待办列表 |
| A09 | 删除任务/笔记/日程，查看当日及历史日志，再恢复 | 回收站内容从普通视图和自动日志隐藏，恢复后按历史重建 |
| A10 | 对回收站实体执行确认后的永久删除并重新生成日志 | 实体正文与应用管理的关联快照/派生记录逻辑清除；新导出不再包含其自动生成内容 |
| A11 | 快捷捕获输入 Markdown 和中英文，按 Enter/Ctrl+Enter | Enter 换行，Ctrl+Enter 成功落盘后收起；候选词确认不导致提交；Markdown 清单和日期文字不自动转为任务或日程 |
| A12 | 草稿保存后 Esc/失焦/重启；模拟写入失败和快速重复提交 | 草稿恢复；失败不清空；事务失败不出现假成功；重复提交不产生两条记录 |
| A13 | 模拟不同耗时的连续草稿写入 | 老请求不能覆盖新内容；显示保存状态与实际落盘状态一致 |
| A14 | 在一个窗口创建/完成/恢复项目，同时观察其他窗口 | 其他窗口及时一致刷新，监听清理正确，不依赖重启才能看到变化 |
| A15 | 创建 23:30 到次日 00:30 的日程及多日全天日程 | 每个重叠日期正确出现；结束日/开始日边界符合已定义语义 |
| A16 | 改为未来日期，打开日列表，再返回今天 | 可以创建和查看跨天安排；过去日程仍标为计划，不伪称已经参加 |
| A17 | 周一任务未完成，周二完成；周三首次查看周一日志 | 周一截至结束仍待办，周二有完成记录；不读取周三当前状态冒充周一状态 |
| A18 | 多次生成同一天日志，在汇总间写入手写补充；当天继续保存新数据 | 幂等无重复，自动区按已保存数据更新，补充文字不被覆盖；同时间戳事件有稳定顺序 |
| A19 | 应用零点未运行，第二天启动；再模拟时区与夏令时边界变化 | 可补齐历史，既有归属日期不漂移；没有真实等待一天或改系统时间 |
| A20 | 同日完成后重新打开；后续改标题/计划日期 | 日志遵循 CONTRACTS 中的事件规则，当前状态正确，旧日志不被无意改写 |
| A21 | Markdown 中插入原始 HTML、脚本协议、远程图像和代码 | 不执行脚本，不意外发起远程图像请求；代码安全呈现，正常外链受控 |
| A22 | 尝试不合法 IPC 数据、未授权来源、任意路径/SQL | 在主进程边界被拒绝；renderer 无 Node/数据库直接访问权限 |
| A23 | 从空测试目录首次启动、重启、迁移旧 schema | SQLite 真持久化，迁移保留数据；普通启动不注入 demo 数据 |
| A24 | 在 Electron 和实际 Windows 打包产物中进行 SQLite 读写 | 原生模块可加载，打包外部资源完整，退出重启后数据仍存在 |
| A25 | 快捷键已被占用、更改快捷键、托盘退出和窗口关闭 | 冲突有提示且保留可用入口；不残留重复注册；应用能明确退出 |
| A26 | 导出含中文、代码块、手写补充和删除项目的 Daily Log | UTF-8 Markdown 正确；隐藏实体不进入新导出；手写区不会因出现同词而被删除；独立副本边界说明清楚 |
| A27 | 关闭开发服务器，断网运行 Windows 构建，数据目录含空格/中文 | 应用独立运行，实际保存与恢复正常；测试不污染正式 userData |
| A28 | 在固定配置记录发布版启动/闲置/输入/大量记录表现 | 报告真实总进程内存、CPU 与方法；不冒充单进程数字或虚构“原生级”指标 |

## 最小演示闭环
使用独立 demo 数据目录和可注入测试时钟，创建昨日待办、今日跨午夜日程、中英文 Markdown 笔记。重启后确认仍在；切到下一天，完成任务，查看两日日志，验证旧日仍保留当时状态；删除、恢复、永久删除并导出。最后在真实桌面执行 Win+D 与覆盖/返回桌面检查。

演示可证明已执行的情境，不等于上述全部系统组合已经通过。阶段报告必须区分：自动通过、人工通过、失败、被环境阻塞、未执行。
