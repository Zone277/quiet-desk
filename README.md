# QuietDesk

QuietDesk 是一款面向 Windows 11 的本地桌面小组件，目标是在桌面上安静地呈现待办、日程和笔记，并提供快速记录入口。

## 当前版本

当前版本为早期预览版，主要提供：

- Windows 桌面挂接与兼容模式诊断。
- 可调整大小的桌面窗口。
- 本地 SQLite 数据库和基础笔记存储。
- Widget、Capture 和 Library 三类窗口的基础框架。

任务管理、完整笔记编辑、日程浏览、快捷捕获、Markdown 预览和 Daily Log 尚未开放，请勿将当前版本用于重要数据。

## 系统要求

- Windows 11 x64。
- 建议使用 100% 或 150% 显示缩放。
- 应用无需管理员权限。

## 安装与启动

1. 获取 `QuietDesk 0.1.0.exe` 便携版。
2. 将文件放在普通可写目录中，例如“下载”或“应用”目录。
3. 双击启动。首次启动会在当前 Windows 用户的应用数据目录中创建 QuietDesk 专属数据文件。
4. 如 Windows 显示安全提示，请核对文件来源后再决定是否运行。

便携版不需要安装。退出应用后，可以直接删除程序文件；本地数据不会随程序文件自动删除。

## 使用说明

启动后，Widget 会尝试挂接到 Windows 桌面：

- `DESKTOP ATTACHED`：窗口已挂接到桌面层。
- `COMPATIBILITY MODE`：桌面挂接不可用，窗口以兼容模式显示。
- `CHECKING DESKTOP HOST`：正在检查桌面环境。

可以拖动窗口边缘调整大小。界面中的状态区域会显示窗口尺寸、显示器缩放和桌面挂接信息；“Retry desktop host”可重新尝试挂接，“Interaction count”用于确认窗口可以正常接收点击。

Capture 和 Library 目前只显示功能尚未开放的提示，不会提供完整的捕获或资料库操作。

## 数据与隐私

- 数据保存在本机，不使用账号或云同步。
- 应用不会把笔记内容发送到远程服务。
- 删除便携版程序不会自动删除用户数据。
- 当前为早期预览版，升级前请自行备份重要数据。

## 已知限制

- 在部分 150% DPI 环境中，窗口实际边界可能比目标尺寸多出数个像素。
- Windows 桌面挂接依赖系统 Shell 的内部窗口结构，系统更新后可能进入兼容模式。
- 多显示器、不同 DPI、Explorer 重启和睡眠唤醒组合尚未完整验证。
- 当前版本使用默认应用图标，未提供代码签名。

## 退出与清理

关闭当前窗口即可结束应用。若需要清除本地数据，请先退出 QuietDesk，再通过 Windows 应用数据目录删除 QuietDesk 对应文件夹。执行前请确认其中没有需要保留的数据。
